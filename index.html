ДИАГНОСТИКА СЛУЖБ

Последние записи

Выберите службу и число строк. Перед чтением панель попросит подтверждение. Поиск ограничен последними 24 часами, максимум 100 строками, 8 КБ вывода и 5 секундами работы Agent.

Автообновление заменяет текущий снимок не чаще чем раз в 30 секунд и завершается через пять минут. Это повторное чтение последних строк: при ротации журнала или более чем 100 новых строках между снимками ранние записи могут не попасть на экран.

На Agent требуется отдельное разрешение на чтение журналов.

Запрос ещё не отправлен.


          
Записи могут содержать чувствительные данные приложения. Hub держит текст до пяти минут в памяти (не больше 32 результатов); в SQLite остаются только состояние задания и аудит без строк журнала. Выход, смена пароля или перезапуск Hub удаляют текст раньше.

ОПОВЕЩЕНИЯ
Когда сообщать о проблеме

          
Задайте уровень и время, в течение которого проблема должна сохраняться. Новые пороги применяются при следующем измерении, а время без связи — при ближайшей проверке.

          

            

              

              

              

              

              

            

            
Допустимые значения для нагрузки, памяти и диска: от 1 до 100%.

            
Если за это время не придёт новое измерение, Hub начнёт отсчёт задержки тревоги. От 10 секунд до 24 часов; обычное значение — 120 секунд.

            
0 минут — тревога сразу. При большем значении Hub ждёт устойчивого превышения порога или отсутствия связи. Тревога CPU, памяти, диска и служб подтверждается новым измерением; отсутствие связи проверяется каждые 10 секунд.

            

            

            

          

        

        

          
ФАЙЛОВАЯ СИСТЕМА
Оповещение о свободных inode

          
Inode — записи для файлов и каталогов. Даже при свободном месте на диске их нехватка может мешать создавать файлы. Правило действует для корневой файловой системы на всех серверах.

          
Загружаем правило…

          

            
            

              

              

            

            
Порог больше 0 и не выше 100%; задержка от 30 секунд до 24 часов. Hub ждёт повторного подтверждённого измерения. Если Agent не передал согласованные счётчики, состояние неизвестно и восстановление не объявляется.

ЛОКАЛЬНЫЙ ПУТЬ
Применить путь панели?
Локальный Web может перезапуститься. Туннель SSH сохранится; после перехода на новый путь потребуется снова войти. Ответ может пропасть, поэтому панель сохранит ID запроса для проверки.

  
ПЕРЕХОД К HTTPS
Отключить локальную настройку?
Специальный локальный путь будет снят; останется адрес /sovagrid/monitoring/ через тот же SSH-туннель. Путь и правило для / сохранятся на этом устройстве как черновик для публичного HTTPS. Для публичного сайта значение «Не занимать /» обычно даёт 404 на корне, даже если локальный корень раньше открывал панель. Затем можно настроить IP или домен в соседнем разделе.

  
ПУБЛИЧНЫЙ АДРЕС
Применить новый адрес?
Web может перезапуститься на несколько минут. После перехода на новый адрес понадобится снова войти; данные входа не передаются через ссылку. При потере ответа панель проверит состояние запроса.

  
    
SovaGrid — как приложение
Та же панель, отдельная иконка. Установку подтверждаете вы в браузере или меню устройства.

    
Приложение будет открывать этот адрес:

    
    
Для ручного добавления на экран сначала откройте постоянный адрес панели. Он сохранит работу ярлыка, если администратор позже изменит путь панели.

    
Открыть постоянный адрес для установки

    

    
Для установки откройте защищённый HTTPS-адрес панели. Обычный HTTP на удалённом сервере не подходит для защищённого веб-приложения. Локальный адрес работает только на устройстве, где доступен сервер или туннель.

    

    
Установить через браузер
    Официальная инструкция
    
    
    Для актуальных данных нужна связь с Hub. Пароли, сеанс, команды и метрики не сохраняются для работы без сети. После открытия с новой иконки может потребоваться повторный вход.
